# Restaurant & Coffee Shop POS System

A comprehensive Point of Sale (POS) system built with Angular for restaurants and coffee shops. This system provides complete management of orders, products, inventory, sales, customers, and staff.

## Features

- **Point of Sale (POS)**: Complete order management system
- **Product Management**: Manage menu items, beverages, and food products
- **Sales Management**: Track and manage all sales transactions
- **Customer Management**: Maintain customer database and order history
- **Inventory Management**: Track stock levels and manage inventory
- **Reports & Analytics**: Comprehensive reporting and analytics dashboard
- **Accounting**: Financial management and accounting features
- **HR Management**: Staff and employee management
- **Role-Based Access Control**: Multiple user roles with appropriate permissions

## User Roles

- Super Admin
- Restaurant Manager
- Shift Manager
- Waiter
- Cashier
- Bartender
- Host
- Chef
- Kitchen Staff
- Accountant
- Inventory Manager
- Store Manager
- Sales Staff
